# Estudo em JavaScript

Este repositório contém os projetos e exercícios desenvolvidos durante o curso **[JavaScript Tutorial Full Course - Beginner to Pro](https://www.youtube.com/watch?v=EerdGm-ehJQ&t=79672s)** do canal SuperSimpleDev.

## Sobre o Curso

O curso completo, com duração de 22 horas, abrange desde os conceitos básicos até tópicos avançados de JavaScript, incluindo:

-   Fundamentos de JavaScript (variáveis, tipos de dados, condicionais, loops)
-   Funções e Objetos
-   DOM (Document Object Model) e manipulação de eventos
-   Arrays e Loops avançados
-   Projetos práticos como:
    -   Lista de Tarefas (To-Do List)
    -   Jogo da Velha (Tic-Tac-Toe)
    -   Clone da página da Amazon
-   Conceitos de backend, APIs, Promises e `async/await`
